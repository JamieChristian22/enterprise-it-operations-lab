# Customer Communication Standard

## Opening Response
- Acknowledge the issue.
- Restate impact.
- Confirm ownership.
- Ask only necessary questions.
- Give a realistic next update time.

## Progress Update
- Explain what has been checked.
- Avoid excessive technical detail.
- State the next action.
- Communicate delays early.

## Closure Message
- State what was fixed.
- Summarize verification.
- Ask the user to confirm.
- Provide a reference number.
- Use a consistent signature.

## Prohibited Practices
- Blaming the user
- Promising an unsupported deadline
- Sharing sensitive internal details
- Closing without verification
- Using unexplained jargon
