# Evidence Handling Standard

## Purpose
Ensure diagnostic evidence is accurate, minimal, and safe for internal use or public portfolio publication.

## Rules
- Use fictional identities in public artifacts.
- Redact real email addresses, hostnames, tenant IDs, IP addresses, tokens, and customer data.
- Do not publish credentials, authentication codes, registry secrets, or full sign-in logs.
- Preserve original timestamps when evidence is used internally.
- Record the tool and source of each artifact.
- Do not alter evidence in a way that changes technical meaning.
- Label generated portfolio mockups as simulated evidence when appropriate.
- Store exported logs in access-controlled locations.
- Delete temporary files according to retention policy.

## Evidence Register Fields
- Evidence ID
- Ticket ID
- File name
- Source tool
- Collection time
- Collector
- Redaction status
- Purpose
