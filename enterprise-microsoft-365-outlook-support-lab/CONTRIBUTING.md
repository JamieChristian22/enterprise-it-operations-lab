# Contributing

This repository is a personal portfolio project. Improvements should preserve:
- Fictional data
- Technical consistency
- Nondestructive troubleshooting
- Clear evidence-to-document mapping
- PowerShell safety and readability

Before submitting changes:
1. Check Markdown formatting.
2. Validate PowerShell syntax on Windows.
3. Confirm no secrets or personal information are present.
4. Update CHANGELOG.md.
