# 📖 Overview

This folder contains the complete evidence package collected while resolving a simulated enterprise Microsoft 365 Outlook incident.

Each screenshot represents a real troubleshooting step performed during the investigation and demonstrates the workflow expected of a Tier 1 / Tier 2 Help Desk Technician supporting Microsoft 365 Enterprise environments.
