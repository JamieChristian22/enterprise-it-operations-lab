# 📖 Project Overview

This repository simulates a real enterprise Help Desk incident involving Microsoft Outlook failing to launch on a Windows 11 Enterprise workstation.

The project follows a complete incident lifecycle from ticket creation through investigation, diagnostics, remediation, validation, documentation, and Knowledge Base publication.

Unlike a simple troubleshooting lab, this project demonstrates how an enterprise support technician documents work, validates findings, and communicates technical information throughout an incident.

# 🎯 Objectives

- 🎫 Handle an enterprise support incident

- 📧 Troubleshoot Microsoft Outlook startup failures
- 💻 Perform Windows diagnostics
- 🌐 Validate network connectivity

- 📊 Conduct root cause analysis
