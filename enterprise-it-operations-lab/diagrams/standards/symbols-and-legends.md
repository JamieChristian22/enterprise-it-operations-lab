# Symbols and Legends

| Symbol | Meaning |
|---|---|
| Rounded rectangle | System, service, process, or zone |
| Diamond | Decision point |
| Ellipse | External actor or network |
| Solid arrow | Data, traffic, or process flow |
| Bidirectional arrow | Replication or two-way trust |
| Red fill | Risk, incident, rollback, or security boundary |
| Green fill | Completed, validated, or healthy state |
