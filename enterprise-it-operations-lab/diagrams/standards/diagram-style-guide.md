# Diagram Style Guide

- Use left-to-right layouts for workflows.
- Use top-to-bottom layouts for architecture hierarchies.
- Label security boundaries, subnets, and trust relationships.
- Use consistent colors:
  - Blue: core infrastructure
  - Green: healthy or approved state
  - Yellow: review or boundary
  - Red: risk, rollback, or security
  - Purple: identity or PKI
- Include editable source and rendered output.
- Use descriptive file names and version-controlled documentation.
