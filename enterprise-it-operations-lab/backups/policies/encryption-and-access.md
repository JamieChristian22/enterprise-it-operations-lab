# Encryption and Access

## Controls

- Encrypt backup traffic.
- Encrypt backup repositories.
- Store keys separately from backup data.
- Restrict backup administrator membership.
- Separate backup operator and domain administrator duties.
- Require MFA for cloud backup consoles.
- Audit backup deletion and retention changes.
- Review access quarterly.

## Prohibited Practices

- Shared backup administrator accounts
- Backup credentials embedded in scripts
- Domain-joined immutable repositories without compensating controls
- Unlogged backup deletion
