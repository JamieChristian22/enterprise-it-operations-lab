# Immutable Backup Standard

## Requirements

- One recovery copy must be immutable or offline.
- Immutability period must exceed the likely incident dwell and detection window.
- Backup operators cannot shorten retention without separate approval.
- Deletion events must be alerted.
- Immutable restore testing must occur quarterly.
