# Processed Enterprise IT Operations Datasets

This folder contains cleaned and analytics-ready versions of the raw Northstar Services datasets.

## Processing applied

- Standardized casing and identifiers
- Removed duplicate primary keys
- Parsed and normalized timestamps
- Added month and date dimensions
- Added SLA, risk, compliance, success, and follow-up flags
- Added derived hours, annualized costs, free-capacity measures, and target results
- Preserved source values needed for traceability

All records remain synthetic and are intended for portfolio and lab use.
