# Raw Enterprise IT Operations Datasets

This folder contains deterministic synthetic datasets for portfolio and lab use.

## Included datasets

| File | Rows | Purpose |
|---|---:|---|
| service_tickets_2026.csv | 1,200 | Service desk SLA, FCR, CSAT, reopen, and resolution analysis |
| infrastructure_metrics.csv | 5,000 | CPU, memory, disk, availability, and alert trends |
| backup_jobs.csv | 1,080 | Backup success, restore testing, repository, and job duration |
| vulnerability_findings.csv | 600 | Severity, remediation status, age, and exception analysis |
| patch_compliance.csv | 360 | Platform and deployment-ring patch compliance |
| endpoint_assets.csv | 300 | Endpoint inventory, assignments, status, and replacement cost |
| identity_users.csv | 250 | User, MFA, licensing, status, and sign-in analysis |
| cloud_resource_inventory.csv | 180 | Cloud cost, tagging, monitoring, backup, and ownership |
| change_records.csv | 150 | Change type, risk, rollback, and incident correlation |
| cmdb_servers.csv | 60 | Server configuration items and ownership |
| major_incidents.csv | 40 | MTTR, user impact, service, and root-cause analysis |

All names, systems, users, costs, incidents, and records are fictional.
