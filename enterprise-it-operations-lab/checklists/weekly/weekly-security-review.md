# Weekly Security Review Checklist

- [ ] Review privileged-group changes.
- [ ] Review local administrator changes.
- [ ] Review suspicious sign-ins.
- [ ] Review Defender and malware alerts.
- [ ] Review repeated SSH failures.
- [ ] Review firewall changes.
- [ ] Review vulnerability exceptions.
- [ ] Review disabled security controls.
- [ ] Review unresolved high-risk findings.
- [ ] Record escalations and evidence.
