# Weekly Infrastructure Health Checklist

- [ ] Review server availability.
- [ ] Review AD replication and DNS health.
- [ ] Review failed services and recurring events.
- [ ] Review capacity trends.
- [ ] Review patch exceptions.
- [ ] Review backup and restore status.
- [ ] Review PKI expiration risk.
- [ ] Review monitoring coverage gaps.
- [ ] Review open infrastructure incidents.
- [ ] Record owners and due dates.
