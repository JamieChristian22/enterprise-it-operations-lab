## Monitoring and Alerts

- [ ] Review all active P1 and P2 alerts.
- [ ] Confirm overnight alerts were acknowledged.
- [ ] Verify alert ownership and ETA.
- [ ] Confirm monitoring targets are reporting.
- [ ] Review alert noise or duplicate alerts.

## Core Services

- [ ] Validate Active Directory authentication.
- [ ] Validate DNS resolution.
- [ ] Confirm DHCP service and scope availability.
- [ ] Confirm VPN and WAN health.
- [ ] Confirm Microsoft 365 service health.
- [ ] Confirm critical internal applications are available.

## Systems

- [ ] Review failed Windows services.
- [ ] Review failed Linux systemd units.
- [ ] Review disk, memory, and CPU warnings.
- [ ] Review critical event logs.
- [ ] Confirm time synchronization.

## Backup

- [ ] Confirm scheduled jobs completed.
- [ ] Review failed or stale backups.
- [ ] Confirm immutable-copy health.
- [ ] Escalate any RPO risk.

## Service Desk and Change

- [ ] Review unassigned tickets.
- [ ] Review overdue P1 and P2 tickets.
- [ ] Review today's approved changes.
- [ ] Review maintenance windows and conflicts.
