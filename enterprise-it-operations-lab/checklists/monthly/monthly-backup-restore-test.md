# Monthly Backup Restore Test Checklist

- [ ] Select workload and recovery point.
- [ ] Confirm approved isolated target.
- [ ] Record RTO and RPO target.
- [ ] Restore data or service.
- [ ] Validate checksum or integrity.
- [ ] Validate permissions.
- [ ] Validate application or service function.
- [ ] Record elapsed time.
- [ ] Obtain service-owner approval.
- [ ] Document lessons learned.
