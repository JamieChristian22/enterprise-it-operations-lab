# Security Baseline Review Checklist

- [ ] Confirm Windows Defender status.
- [ ] Confirm firewall profiles.
- [ ] Confirm PowerShell logging.
- [ ] Confirm Windows LAPS.
- [ ] Confirm SMBv1 disabled.
- [ ] Confirm Linux SSH hardening.
- [ ] Confirm auditd active.
- [ ] Confirm sudo access reviewed.
- [ ] Document exceptions.
- [ ] Retain evidence.
