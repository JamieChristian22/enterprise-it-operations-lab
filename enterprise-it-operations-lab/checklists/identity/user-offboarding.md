# User Offboarding Checklist

- [ ] Validate approved termination request.
- [ ] Disable account at approved time.
- [ ] Revoke sessions and tokens.
- [ ] Remove privileged roles.
- [ ] Reset or remove MFA methods.
- [ ] Convert or delegate mailbox if approved.
- [ ] Preserve required data.
- [ ] Remove group and application access.
- [ ] Recover device and assets.
- [ ] Record evidence and close request.
