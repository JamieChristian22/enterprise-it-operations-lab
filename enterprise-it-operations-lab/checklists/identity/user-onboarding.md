# User Onboarding Checklist

- [ ] Validate approved HR request.
- [ ] Confirm legal name, manager, department, and start date.
- [ ] Create Active Directory account.
- [ ] Assign required groups.
- [ ] Assign Microsoft 365 license.
- [ ] Provision mailbox and collaboration access.
- [ ] Configure MFA registration.
- [ ] Provide device and access instructions.
- [ ] Validate account and mailbox.
- [ ] Record evidence and close request.
