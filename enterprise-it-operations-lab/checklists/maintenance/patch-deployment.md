# Patch Deployment Checklist

- [ ] Confirm approved updates.
- [ ] Confirm backup.
- [ ] Confirm pilot ring.
- [ ] Record pre-patch state.
- [ ] Install updates.
- [ ] Reboot if required.
- [ ] Validate services.
- [ ] Validate business application.
- [ ] Review logs.
- [ ] Update compliance record.
- [ ] Roll back if trigger met.
