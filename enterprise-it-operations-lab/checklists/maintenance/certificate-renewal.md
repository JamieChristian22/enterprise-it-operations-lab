# Certificate Renewal Checklist

- [ ] Confirm certificate owner.
- [ ] Confirm expiration date.
- [ ] Confirm template and EKU.
- [ ] Confirm subject and SAN values.
- [ ] Request or renew certificate.
- [ ] Bind or deploy certificate.
- [ ] Validate chain.
- [ ] Validate revocation.
- [ ] Validate application.
- [ ] Remove superseded certificate.
- [ ] Update inventory.
