# Server Maintenance Checklist

## Pre-Maintenance

- [ ] Approved change record.
- [ ] Maintenance window confirmed.
- [ ] Backup or snapshot verified.
- [ ] Dependencies documented.
- [ ] Monitoring maintenance mode enabled.
- [ ] Capacity and health baseline captured.
- [ ] Rollback plan reviewed.

## Implementation

- [ ] Perform approved work.
- [ ] Record deviations.
- [ ] Reboot if required.
- [ ] Confirm services started.

## Validation

- [ ] Validate application.
- [ ] Validate network and authentication.
- [ ] Review event logs.
- [ ] Confirm monitoring healthy.
- [ ] Remove maintenance mode.
- [ ] Attach evidence and close change.
