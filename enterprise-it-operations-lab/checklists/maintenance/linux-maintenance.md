# Linux Maintenance Checklist

- [ ] Confirm approved change.
- [ ] Confirm backup.
- [ ] Check filesystem capacity.
- [ ] Review failed units.
- [ ] Review package-manager health.
- [ ] Apply approved updates.
- [ ] Restart required services.
- [ ] Validate SSH access.
- [ ] Validate application.
- [ ] Review journal logs.
- [ ] Record evidence.
