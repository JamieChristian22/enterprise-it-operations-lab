# Security Incident Checklist

- [ ] Preserve evidence.
- [ ] Confirm affected identities and assets.
- [ ] Contain compromised accounts or systems.
- [ ] Revoke sessions and credentials.
- [ ] Block malicious sources.
- [ ] Review persistence.
- [ ] Notify security leadership.
- [ ] Recover from clean state.
- [ ] Validate monitoring.
- [ ] Complete incident review.
