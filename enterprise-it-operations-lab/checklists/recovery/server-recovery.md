# Server Recovery Checklist

- [ ] Declare recovery scope.
- [ ] Confirm RTO and RPO.
- [ ] Select recovery point.
- [ ] Provision isolated target.
- [ ] Restore operating system and data.
- [ ] Restore configuration.
- [ ] Validate security controls.
- [ ] Validate identity and network.
- [ ] Validate application.
- [ ] Obtain owner approval.
