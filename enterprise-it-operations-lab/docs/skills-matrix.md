## Target role alignment
### IT Support Engineer / Help Desk Tier 2
Strongest evidence: identity troubleshooting, Microsoft 365 support, endpoint compliance, ticket triage, escalation, and knowledge documentation.

### Junior Systems Administrator
Strongest evidence: AD DS, DNS, Group Policy, server baselines, patching, backup, access control, and PowerShell validation.

### Cloud Operations Analyst / Cloud Support Associate
Strongest evidence: AWS VPC and EC2 operations, CloudWatch alerts, Systems Manager, backup, Terraform, incident response, and capacity review.

### Infrastructure Support Engineer
Strongest evidence: hybrid architecture, operational monitoring, change control, troubleshooting, recovery, and cross-platform administration.

## Resume-ready project summary
Built and documented a simulated hybrid IT operations environment spanning Active Directory, Windows and Linux administration, Microsoft 365, Intune, AWS, monitoring, backup, incident response, change control, and Terraform. Created repeatable operating procedures, troubleshooting runbooks, service objectives, and evidence traceability to demonstrate job-ready support and infrastructure practices.
