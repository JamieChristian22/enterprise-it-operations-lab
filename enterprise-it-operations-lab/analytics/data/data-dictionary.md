# Data Dictionary

| Dataset | Purpose | Key Measures |
|---|---|---|
| `service_tickets.csv` | Service desk performance | Resolution time, FCR, CSAT, SLA |
| `patch_compliance.csv` | Patch posture | Assets, compliant assets, exceptions |
| `backup_jobs.csv` | Backup reliability | Job success and failure |
| `cloud_costs.csv` | Cloud spend | Monthly cost by provider |
| `vulnerability_findings.csv` | Security remediation | Severity, age, status |
| `change_records.csv` | Change performance | Success, rollback, incident impact |
| `major_incidents.csv` | Critical outage impact | MTTR and users affected |
