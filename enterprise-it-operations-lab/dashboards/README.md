A complete enterprise dashboard and reporting package covering executive operations, service desk, infrastructure, security, cloud, backup, patching, monitoring, Microsoft 365, Active Directory, change management, and PKI.

## Centerpiece

`executive/enterprise-it-operations-dashboard.xlsx`

The workbook contains:

- Executive KPI scorecard
- Service desk trend dashboard
- Infrastructure health
- Security events
- Cloud cost
- Backup success
- Patch compliance
- Change performance
- Identity compliance
- PKI health
- Source-data index

All datasets are synthetic and designed for portfolio demonstration.
