# IT Automation Script Collection

This folder contains 20 PowerShell scripts designed for repeatable Help Desk and junior-administrator tasks.

## Operating Standard
- Run from a test environment first.
- Use a least-privileged account.
- Use `-WhatIf` on scripts that support changes.
- Store logs and reports outside public repositories when they contain real identities.
- Review generated CSV files before distribution.
- Never hard-code passwords or recovery keys.
