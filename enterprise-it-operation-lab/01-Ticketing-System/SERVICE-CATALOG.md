# IT Service Catalog

| Service | Examples | Approval | Target |
|---|---|---|---|
| Account Access | Password reset, unlock, MFA registration | Identity verification | Same day |
| Employee Lifecycle | New hire, transfer, termination | Manager and HR | 1–3 business days |
| Software | Install, update, remove, license | Manager for paid apps | 1–3 business days |
| Hardware | Laptop, monitor, dock, peripherals | Manager for new hardware | 3–5 business days |
| Microsoft 365 | Outlook, Teams, OneDrive, shared mailbox | Owner approval for shared resources | 1–3 business days |
| Network | Wi-Fi, VPN, DNS, wired connection | None unless access change | Same day |
| File Access | Department share, project folder | Data owner approval | 1 business day |
| Security | Phishing, suspicious sign-in, malware | Immediate security review | Immediate |
