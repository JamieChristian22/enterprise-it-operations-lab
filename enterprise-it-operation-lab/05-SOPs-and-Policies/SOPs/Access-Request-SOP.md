# Access Request SOP

## Purpose
Provide a consistent, secure, and auditable process for CTS IT operations.

## Procedure
Require manager and data-owner approval; use role-based groups; avoid direct permissions; validate least privilege; test access with the requester; record approver and group; include access in quarterly review.

## Required Ticket Evidence
Requester, authorization, affected asset, actions, verification, time spent, exceptions, and closure message.

## Quality Check
The agent confirms the outcome with the user or system owner and ensures no sensitive data appears in the ticket.
