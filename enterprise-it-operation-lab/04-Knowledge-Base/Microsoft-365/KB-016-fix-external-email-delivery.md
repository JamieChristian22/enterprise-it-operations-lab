# KB-016: Fix External Email Delivery

## Purpose
Use this article to resolve **fix external email delivery** in the CTS Windows and Microsoft 365 environment.

## Symptoms
- The user cannot complete the expected task or receives a related error.
- The issue may affect one device, one account, or one application.
- The user may report that the function previously worked.

## Likely Causes
- Incorrect or stale configuration
- Cached credentials or application data
- Missing permission or group membership
- Outdated software, driver, or firmware
- Network, DNS, service, or device failure

## Resolution
1. Confirm the user's identity, device, location, and exact error.
2. Determine when the issue started and whether anything changed beforehand.
3. Reproduce the symptom or observe the user's workflow.
4. Check service health, connectivity, account state, permissions, and configuration.
5. Apply the least disruptive fix appropriate to the verified cause.
6. Restart only the affected application or service before restarting the entire device.
7. Re-test the original task with the user.
8. Record the root cause, actions, and result in the ticket.

## Verification
The user completes the original action successfully twice, no related error is present, and dependent services remain available.

## Prevention
- Keep software and drivers current.
- Use approved configurations and role-based access groups.
- Avoid storing outdated passwords in mobile, VPN, or email clients.
- Report recurring symptoms so IT can identify a pattern.

## Escalation
Escalate when the issue affects multiple users, involves suspected compromise, requires server or tenant changes, or remains unresolved after standard diagnostics.

## Estimated Resolution Time
15–45 minutes for a standard single-user case.
