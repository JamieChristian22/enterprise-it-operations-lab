# Role-Based Access Matrix

| Department | File Share | Access Group | Permission |
|---|---|---|---|
| Finance | `\FS01\Finance` | GG-FIN-Share-RW | Modify |
| Human Resources | `\FS01\HR` | GG-HR-Share-RW | Modify |
| Operations | `\FS01\Operations` | GG-OPS-Share-RW | Modify |
| Sales | `\FS01\Sales` | GG-SALES-Share-RW | Modify |
| Marketing | `\FS01\Marketing` | GG-MKT-Share-RW | Modify |
| Customer Success | `\FS01\CustomerSuccess` | GG-CS-Share-RW | Modify |
| Approved Remote Users | VPN | GG-VPN-Users | Connect |
| Approved IT Staff | RDP | GG-RDP-Authorized | Remote interactive logon |

Permissions are granted through groups, never directly to individual users.
