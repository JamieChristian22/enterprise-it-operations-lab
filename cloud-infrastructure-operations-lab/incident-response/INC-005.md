# INC-005: Kubernetes rollout stalled

- **Severity:** SEV-3
- **Environment:** Northstar Retail cloud operations lab
- **Started:** 2026-07-29 18:05 UTC
- **Resolved:** 2026-07-29 18:28 UTC
- **Duration:** 23 minutes
- **Incident commander:** Jamie Christian II
- **Customer impact:** No external outage because PDB and existing replicas preserved service.

## Detection
The event was detected through configured infrastructure or application monitoring and acknowledged by Cloud Operations within five minutes.

## Timeline
- 2026-07-29 18:05 UTC — Alert triggered and incident opened.
- Five minutes later — Impact confirmed and unrelated changes frozen.
- During investigation — Metrics, logs, target health, and recent change history correlated.
- 2026-07-29 18:28 UTC — Service restored and validation completed.

## Root cause
Deployment referenced a nonexistent container tag, causing ImagePullBackOff.

## Resolution
Rolled back deployment, required immutable digest validation in CI, and added pre-deployment image check.

## Five whys
1. Service degraded because the affected component could not complete its expected operation.
2. The component failed because a configuration or software change violated an operational dependency.
3. The dependency was not caught before deployment because the validation control did not cover that failure mode.
4. The control gap existed because acceptance criteria focused on deployment success rather than end-to-end service health.
5. The process lacked an automated post-deployment gate tied to the service SLO.
