# SEC-2026-001 — Phishing Investigation

## Detection

A Finance user reported a message impersonating Microsoft 365 support and requesting credential verification.

## Investigation

- Sender domain was newly registered.
- Link redirected to a credential-harvesting page.
- User did not enter credentials.
- Search identified three delivered copies.
- No suspicious sign-ins were found.

## Response

Messages were quarantined, sender and URL blocked, and recipients notified.

## Outcome

No compromise confirmed. The message was added to security-awareness training.
