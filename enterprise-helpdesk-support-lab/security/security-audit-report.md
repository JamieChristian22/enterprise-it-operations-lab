# Security Control Audit Report

## Scope

The review assessed identity, endpoint, access, vulnerability, and incident-response controls.

## Results

| Control | Result |
|---|---:|
| BitLocker coverage | 100% |
| Defender health | 97.9% |
| Critical patch compliance | 95.8% |
| MFA registration | 96.0% |
| Local administrator compliance | 93.8% |
| Access review completion | 100% |
| Security event closure | 100% |

## Findings

1. Three users required MFA enrollment.
2. Three endpoints exceeded the local administrator baseline.
3. Five laptops required firmware updates.
4. One dormant privileged account was removed.

## Conclusion

The environment met most targets. Least-privilege compliance is the highest-priority improvement.
