# Patch Management Policy

## Cadence

- Critical exploited vulnerabilities: emergency deployment
- Critical security patches: within 72 hours
- High security patches: within 7 days
- Standard monthly updates: approved maintenance cycle
- Firmware: quarterly or risk-based

## Controls

- Test group before broad deployment
- Backup or rollback option
- User communication for disruptive updates
- Deployment monitoring
- Failure and exception tracking
- Post-deployment compliance validation
