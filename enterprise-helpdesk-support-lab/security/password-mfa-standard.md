# Password and MFA Standard

## Password Requirements

- Minimum length: 14 characters
- Complexity enabled
- Password history: 24
- Temporary passwords must be changed at first sign-in
- Shared passwords are prohibited
- Privileged accounts use separate credentials
- Suspected compromise requires immediate reset

## MFA Requirements

- MFA required for Microsoft 365, VPN, and privileged access
- Approved methods: authenticator app, FIDO2 security key, Temporary Access Pass for recovery
- SMS is recovery-only where permitted
- Users must report unexpected prompts
- Lost devices require method removal and re-registration
