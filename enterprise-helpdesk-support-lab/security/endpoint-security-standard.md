# Endpoint Security Standard

Managed endpoints must have:

- Supported operating system
- Current critical patches
- BitLocker or approved device encryption
- Microsoft Defender enabled and healthy
- Host firewall enabled
- Standard-user access by default
- Approved software only
- Automatic screen lock
- MDM or endpoint management enrollment
- Recovery key escrow
- Security event reporting

Exceptions require documented approval, compensating controls, owner, and expiration.
