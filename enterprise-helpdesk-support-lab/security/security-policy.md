# Information Security Policy

## Purpose

This policy establishes minimum requirements for protecting identities, endpoints, data, services, and administrative access.

## Requirements

1. All users must use unique credentials and approved MFA.
2. Administrative access must follow least privilege.
3. Managed Windows endpoints must use BitLocker.
4. Microsoft Defender must remain enabled and healthy.
5. Critical patches must be deployed within defined timelines.
6. High and critical vulnerabilities must be tracked to closure.
7. Suspicious email, malware, and account activity must be reported immediately.
8. Quarterly access reviews are required for privileged and sensitive access.
9. Security events must have unique records, owners, response evidence, and outcomes.
10. Lost or stolen devices require immediate security escalation.
11. Sensitive data must not be stored in unapproved locations.
12. Security exceptions require documented risk acceptance and expiration.

## Roles

| Role | Responsibility |
|---|---|
| Service Desk | Identity verification, endpoint triage, security event intake |
| Security Operations | Investigation, containment, risk and control oversight |
| Systems Administration | Patching, endpoint configuration, privileged access |
| Microsoft 365 Administration | MFA, identity, and cloud access controls |
| Service Owners | Risk acceptance and recovery confirmation |
| Users | Follow policy and report suspicious activity |
