# Phishing Response Playbook

1. Preserve the message and headers.
2. Confirm whether the user clicked, replied, downloaded, or entered credentials.
3. Quarantine the message.
4. Search for related messages.
5. Block malicious sender, domain, URL, or hash as appropriate.
6. Reset credentials when exposure is possible.
7. Revoke active sessions.
8. Review sign-in and mailbox activity.
9. Run endpoint scan when files were opened.
10. Notify affected users.
11. Document outcome and preventive action.
