# Pre-Change and Post-Change Checklist

## Pre-Change Readiness

- [x] Unique change ID assigned
- [x] Business justification documented
- [x] Change type selected
- [x] Systems and users affected identified
- [x] Risk score completed
- [x] Dependencies confirmed
- [x] Technical steps peer-reviewed
- [x] Rollback criteria defined
- [x] Rollback steps documented
- [x] Backup or configuration export completed
- [x] Monitoring baseline captured
- [x] Maintenance window confirmed
- [x] Service Desk notified
- [x] End users notified when applicable
- [x] Required approvals recorded
- [x] Administrator access tested
- [x] Validation tests prepared

## Implementation Controls

- [x] Start time recorded
- [x] Stakeholders notified that implementation began
- [x] Steps executed in documented order
- [x] Deviations recorded
- [x] Logs and command output retained
- [x] Service health monitored during implementation

## Post-Change Validation

- [x] Intended configuration confirmed
- [x] Core service functionality tested
- [x] Authentication or access tested
- [x] Representative user test completed
- [x] Monitoring returned to healthy state
- [x] No unexpected events or alerts detected
- [x] Service Desk briefed on outcome
- [x] Users notified of completion
- [x] Evidence linked to the record
- [x] Actual start and end times recorded
- [x] Final status selected
- [x] Lessons learned documented
- [x] Follow-up actions assigned
