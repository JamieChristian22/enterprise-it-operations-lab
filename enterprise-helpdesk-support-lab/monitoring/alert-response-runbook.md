# Alert Response Runbook

## Standard Response

1. Confirm alert ID, time, source, configuration item, and severity.
2. Validate that the condition is current.
3. Determine user and business impact.
4. Assign the correct owner.
5. Collect logs, screenshots, command output, and baseline information.
6. Apply containment or workaround where required.
7. Escalate based on severity and elapsed time.
8. Link an incident for service-impacting conditions.
9. Implement the approved correction.
10. Validate recovery through monitoring and user testing.
11. Document root cause or probable cause.
12. Record preventive action.
13. Close only after the alert remains healthy for the defined observation period.

## Required Closure Evidence

- Healthy monitoring status
- Functional test
- User or service confirmation when applicable
- Resolution notes
- Related incident or change
- Preventive action
