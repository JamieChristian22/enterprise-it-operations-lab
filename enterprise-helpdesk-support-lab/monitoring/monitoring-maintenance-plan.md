# Monitoring Maintenance Plan

## Daily

- Review open critical and high alerts
- Confirm collection agents are reporting
- Review failed synthetic checks
- Validate alert queue ownership

## Weekly

- Review alert aging
- Review recurring alerts
- Review disk and capacity trends
- Validate backup and service-health alerts
- Confirm suppression expiration dates

## Monthly

- Calculate availability
- Review false positives
- Review threshold effectiveness
- Audit routing and escalation
- Test one critical alert path
- Review monitoring gaps from incidents

## Quarterly

- Validate monitoring coverage against asset inventory
- Review service targets
- Update runbooks
- Test major incident notification
