# Data Dictionary

The complete field catalog is included in the workbook's `Data Dictionary` worksheet.

| Field | Description |
|---|---|
| Ticket ID | Unique incident identifier |
| Opened At | Ticket creation timestamp |
| Resolved At | Ticket resolution timestamp |
| Month | Reporting month used for trend analysis |
| Status | Current lifecycle state |
| Priority | Business urgency and impact |
| Category | Primary issue type |
| Department | Requesting business unit |
| Technician | Assigned support analyst |
| Channel | Portal, email, phone, or chat |
| First Response Hours | Time to first analyst response |
| Resolution Hours | Time from open to resolution |
| SLA Target Hours | Target based on priority |
| SLA Met | Whether the service target was achieved |
| First Contact Resolution | Resolved during first interaction |
| Reopened | Ticket reopened after resolution |
| Escalated | Ticket transferred to higher support tier |
| CSAT | Customer satisfaction score |
| Backlog Age Hours | Age of active unresolved ticket |
| Endpoint Compliant | Endpoint meets security baseline |
| Phishing Correct | User classified simulation correctly |
| Knowledge Article Used | Approved KB content used in resolution |
