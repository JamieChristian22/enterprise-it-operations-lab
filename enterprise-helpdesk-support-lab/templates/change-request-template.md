# Change Request Template

## Change Control

Record the change ID, title, type, risk, owner, service owner, requested date, implementation window, and related records.

## Business Justification

Explain the operational, security, compliance, or user-experience reason for the change.

## Scope

List affected users, systems, services, locations, and configuration items.

## Risk Assessment

Evaluate likelihood of failure, user impact, service criticality, security exposure, and rollback complexity.

## Implementation Plan

Document the exact technical sequence, access required, evidence to capture, and responsible implementer.

## Validation Plan

Define service health, functional, user, security, and performance tests.

## Rollback Plan

Define rollback trigger, recovery steps, estimated recovery time, and validation after rollback.

## Approval and Closure

Record approvals, implementation results, deviations, final outcome, and lessons learned.
