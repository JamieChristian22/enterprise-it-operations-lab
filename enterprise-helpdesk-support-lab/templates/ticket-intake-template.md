# Ticket Intake Template

## Record Control

| Field | Required Content |
|---|---|
| Ticket ID | Unique service desk identifier |
| Requester | User's full name and department |
| Contact Method | Portal, email, phone, or chat |
| Date and Time | Exact intake timestamp |
| Category | Identity, software, hardware, network, Microsoft 365, security, or request |
| Priority | Based on impact and urgency |
| Assigned Queue | Responsible support team |

## User-Reported Issue

Document the user's exact symptoms in plain language, including what they were trying to do, what happened instead, and any error message.

## Business Impact

State whether the user is blocked, partially impacted, or has a workaround. Include the number of users, affected service, department, and deadline.

## Initial Evidence

Record the device name, operating system, application version, network state, screenshots, logs, and relevant timestamps.

## Initial Triage

Document verification of service status, account state, connectivity, recent changes, and whether the issue can be reproduced.

## Next Action

State the assigned owner, immediate next step, response target, and expected update time.
