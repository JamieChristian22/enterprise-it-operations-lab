# Root Cause Analysis Template

## Problem Statement

Describe what failed, when it failed, who was affected, and the measurable impact.

## Timeline

Record detection, escalation, investigation, containment, recovery, and closure.

## Five Whys Analysis

1. Explain the immediate technical failure.
2. Explain why that condition existed.
3. Explain why the control or process did not prevent it.
4. Explain why detection or correction was delayed.
5. Identify the underlying process, design, or governance gap.

## Root Cause

State the single primary cause.

## Contributing Factors

Document configuration, process, documentation, monitoring, training, access, dependency, and communication factors.

## Corrective Actions

Assign each preventive action an owner, due date, priority, status, and validation method.
