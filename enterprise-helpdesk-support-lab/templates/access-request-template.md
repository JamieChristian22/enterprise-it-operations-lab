# Access Request Template

## Request Details

Record requester, user receiving access, department, system, requested role, business justification, duration, and manager.

## Approval

Document data owner, system owner, manager, and security approval as required.

## Least-Privilege Review

Confirm that the requested role is the minimum necessary access and does not create a separation-of-duties conflict.

## Implementation

Record the group, role, folder, application, or policy changed.

## Validation

Confirm the user can access the approved resource and cannot access unauthorized resources.

## Review Date

Document expiration or quarterly review requirement.
