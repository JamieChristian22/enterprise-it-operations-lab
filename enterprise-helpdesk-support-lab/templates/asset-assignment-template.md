# Asset Assignment Template

## Asset and User

Record asset ID, serial number, model, assigned user, department, location, issue date, and issuing technician.

## Readiness Verification

Confirm operating system, patching, encryption, endpoint protection, approved software, VPN, and inventory status.

## Condition

Record physical condition, included accessories, and any existing damage.

## User Acceptance

Confirm the user received the device, acceptable-use guidance, support contact details, and return obligations.

## Closure

Update the asset register and assignment history.
