# New-Hire Onboarding Template

## Employee Details

Record employee name, title, department, manager, start date, work location, and employment type.

## Identity Setup

- Create directory account
- Apply naming standard
- Assign organizational unit
- Set temporary password
- Require password change
- Register MFA
- Assign security groups
- Validate sign-in

## Microsoft 365

- Assign license
- Create mailbox
- Configure Teams and OneDrive
- Add approved distribution groups
- Validate Outlook access

## Device and Access

- Assign inventoried device
- Verify encryption and security health
- Configure VPN
- Map approved shared folders
- Install approved software
- Test printing and remote access

## Completion

Record manager confirmation, user validation, asset assignment, documentation links, and closure.
