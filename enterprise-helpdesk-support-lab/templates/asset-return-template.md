# Asset Return Template

## Return Details

Record user, asset ID, serial number, return date, receiving technician, and return reason.

## Inspection

Document physical condition, accessories, power state, encryption, and visible damage.

## Security Actions

Remove user assignment, secure the device, revoke local access, and begin approved sanitization.

## Final Disposition

Record reassignment, repair, stockroom placement, retirement, or certified disposal.

## Closure

Update asset, assignment, repair, and disposal records as applicable.
