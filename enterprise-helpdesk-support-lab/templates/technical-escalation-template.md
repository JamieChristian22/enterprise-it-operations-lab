# Technical Escalation Template

## Escalation Summary

State the issue, affected service, user impact, priority, and exact reason escalation is required.

## Scope

Document the number of affected users, departments, locations, devices, and services.

## Evidence Collected

Include:

- Error messages
- Logs and event IDs
- Command output
- Screenshots
- Timestamps
- Configuration values
- Service-health results

## Troubleshooting Already Completed

List every action already performed and the result of each action.

## Current Workaround

State whether a workaround exists, how reliable it is, and who has been informed.

## Assistance Requested

Specify the exact action needed from the receiving team, such as reviewing a server log, changing a policy, validating a network path, or approving an emergency change.

## Ownership and Communication

Record the receiving team, escalation time, business contact, next update deadline, and current ticket owner.
