# Password Reset Verification Template

## Identity Verification

Use at least two approved verification methods, such as employee ID, manager confirmation, callback to a registered number, approved security questions, or in-person badge verification.

## Reset Actions

- Confirm account status
- Unlock account when appropriate
- Set a temporary password meeting policy
- Require password change at next sign-in
- Revoke sessions when compromise is suspected
- Confirm MFA remains valid
- Document the reset without recording the password

## Validation

Confirm successful sign-in and user access.

## Security Escalation

Escalate unexpected MFA prompts, suspicious sign-ins, repeated lockouts, or suspected social engineering.
