# Problem Record Template

## Problem Statement

Describe the recurring incidents, affected services, frequency, impact, and known workaround.

## Incident Linkage

List all related incident IDs and common symptoms.

## Investigation

Document trend analysis, technical evidence, hypotheses, and eliminated causes.

## Root Cause

State the confirmed underlying cause.

## Known Error

Document the condition, workaround, and user impact.

## Permanent Resolution

Reference the approved change, validation plan, and implementation outcome.

## Closure

Confirm recurrence monitoring, documentation updates, and service owner acceptance.
