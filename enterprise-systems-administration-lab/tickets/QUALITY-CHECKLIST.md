# Ticket Quality Checklist

A ticket is publication-ready only when every item is satisfied.

- [x] Unique incident and realistic title
- [x] Complete ITSM metadata
- [x] Priority supported by impact and urgency
- [x] Exact timestamps and SLA result
- [x] Clear business impact
- [x] Scope and security checks
- [x] Chronological investigation timeline
- [x] Relevant technical commands
- [x] Command results interpreted
- [x] Root cause stated
- [x] Resolution completed
- [x] Validation documented
- [x] Rollback readiness addressed
- [x] Customer communication included
- [x] Evidence filenames listed
- [x] Preventive action included
- [x] Knowledge article linked
- [x] No secrets or unresolved placeholders
