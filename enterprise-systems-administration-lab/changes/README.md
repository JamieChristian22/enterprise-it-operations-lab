# Enterprise Change Management Lab

Portfolio project demonstrating a production-style IT change-management process for Windows Server, Active Directory, DNS, storage, backup, and endpoint operations.

## Environment
- Organization: Northstar Services Group
- Change platform: ServiceNow-style workflow represented through Markdown records
- Core services: Active Directory, DNS, DHCP, file services, backup, Windows Server, Microsoft 365
- Review body: Infrastructure Change Advisory Board
- Change window: Tuesdays and Thursdays, 10:00 PM–12:00 AM ET

## Outcomes
- Defined standard, normal, and emergency change models
- Established risk scoring, approval gates, rollback requirements, and validation evidence
- Completed six realistic changes with implementation, approval, validation, and post-implementation review
- Added PowerShell scripts for pre/post checks, service health, evidence export, and change reporting
- Documented KPIs, CAB minutes, failed-change analysis, and continuous-improvement actions

## Repository Map
- `governance/` policies, standards, roles, risk model, and RACI
- `cab/` charter, agenda, minutes, and approval matrix
- `change-types/` standard, normal, emergency, and expedited procedures
- `requests/` completed production-style change records
- `runbooks/` implementation, validation, rollback, PIR, and communication procedures
- `powershell/` reusable operational validation scripts
- `reports/` monthly reports, KPI summaries, and executive review
- `evidence/` pre-change, post-change, rollback, and validation outputs
- `templates/` reusable operational templates
- `tests/` acceptance-test results and QA summary

## Portfolio Skills Demonstrated
ITIL-aligned change control, CAB governance, risk assessment, implementation planning, rollback design, Windows administration, Active Directory, DNS, storage operations, PowerShell, evidence collection, incident prevention, and executive reporting.
