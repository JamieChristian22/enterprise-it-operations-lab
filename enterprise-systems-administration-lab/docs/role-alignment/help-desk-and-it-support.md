# Role Alignment — Help Desk and IT Support

## Most Relevant Capabilities

- Password resets and account unlocks
- User onboarding and offboarding
- Group membership and access troubleshooting
- Microsoft 365 and Outlook support
- DNS and network diagnostics
- Ticket documentation and knowledge articles
- Escalation using clear evidence

## Best Evidence to Show

- Completed identity-related tickets
- User lifecycle runbooks
- Account-lockout investigations
- Knowledge-base documentation
- PowerShell tools used to collect support evidence

## Interview Positioning

Explain how the lab connects front-line support with systems administration. Emphasize accurate documentation, safe escalation, user communication, and repeatable troubleshooting.
