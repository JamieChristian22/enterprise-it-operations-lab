# Business Scenario

## Organization

Northstar Services Group is a fictional 220-user professional services company with one headquarters office, one branch location, and a hybrid workforce. The company depends on Active Directory, Microsoft 365, Windows file services, internal web applications, centralized monitoring, and protected backups.

## Business Problem

The environment grew without consistent standards. Common issues included manual onboarding, inconsistent server configuration, weak documentation, limited recovery validation, reactive capacity management, and changes implemented without a repeatable approval process.

## Project Objective

Build an enterprise-style systems administration operating model that:

- Standardizes identity and server administration
- Automates repeatable tasks
- Provides measurable monitoring and capacity controls
- Protects critical services through backup and recovery
- Uses documented change and configuration management
- Produces audit-ready evidence and operational reports
- Supports reliable handoff between support, systems, security, and management stakeholders

## Success Criteria

- All critical services have documented owners and recovery targets.
- Administrative changes use implementation, validation, and rollback plans.
- Repetitive tasks are automated where practical.
- Recovery exercises meet documented RTO and RPO objectives.
- Capacity risks are identified before service disruption.
- Evidence is sanitized, traceable, and mapped to portfolio skills.
