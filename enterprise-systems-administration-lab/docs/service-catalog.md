# Service Catalog

| Service | Owner | Priority | Primary Components | Support Objective |
|---|---|---:|---|---|
| Identity and Authentication | Systems Administration | Tier 0 | AD DS, DNS, GPO | Restore authentication first during major incidents |
| Microsoft 365 Productivity | Cloud Administration | Tier 1 | Entra ID, Exchange Online, Teams | Maintain user access and collaboration |
| File Services | Infrastructure | Tier 1 | FS01, NTFS, SMB, backups | Protect departmental data and permissions |
| Internal Web Applications | Application Operations | Tier 2 | IIS01, DNS, certificates | Maintain internal application availability |
| Monitoring and Alerting | IT Operations | Tier 1 | MON01, event collection, health reports | Detect service degradation before outage |
| Backup and Recovery | Infrastructure | Tier 0 | BAK01, immutable repository, offsite copy | Meet documented RPO and RTO objectives |
| Configuration Management | Systems Engineering | Tier 1 | Ansible, DSC, PowerShell | Enforce repeatable and compliant server state |
| Capacity Management | IT Operations | Tier 2 | Metrics, forecasts, reports | Prevent resource exhaustion and unplanned downtime |
| Change Management | IT Operations Governance | Tier 1 | CAB, change records, validation evidence | Reduce failed changes and operational risk |
