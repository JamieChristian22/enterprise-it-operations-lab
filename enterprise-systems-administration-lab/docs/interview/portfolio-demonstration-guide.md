# Portfolio Demonstration Guide

## Ten-Minute Walkthrough

### 1. Business Context

Explain the fictional 220-user organization and the need for consistent operations.

### 2. Architecture

Show the two-domain-controller design, member servers, management plane, monitoring, backup, and automation layers.

### 3. Identity Operations

Demonstrate onboarding, group access, GPO, delegation, and health validation.

### 4. Reliability

Show backup validation, disaster-recovery priorities, recovery exercises, and corrective actions.

### 5. Operations

Show capacity forecasts, change records, rollback plans, and monthly reports.

### 6. Automation

Show one PowerShell script, one Ansible role, and one DSC configuration. Explain inputs, validation, error handling, and repeatability.

### 7. Evidence

Use `evidence-index.md` to show how each claim maps to a file or output.

## Closing Statement

“This is a simulated enterprise lab, not production employment experience. I built it to demonstrate how I would document, automate, validate, and communicate systems-administration work in a real team.”
