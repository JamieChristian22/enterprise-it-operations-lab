# Document Control Standard

## Purpose

Ensure portfolio documentation remains accurate, traceable, consistent, and safe for public review.

## Requirements

- Use descriptive filenames and stable folder locations.
- Record major revisions in `revision-history.md`.
- Remove credentials, tokens, personal data, and proprietary information.
- Verify links and referenced paths before release.
- Mark simulated records clearly.
- Keep technical procedures consistent with the systems they reference.
- Archive superseded documents rather than silently overwriting historical evidence.
