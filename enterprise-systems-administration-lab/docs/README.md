# Enterprise Systems Administration Lab — Documentation Hub

This folder is the authoritative navigation and documentation layer for the Enterprise Systems Administration Lab. It is designed to help recruiters, hiring managers, technical interviewers, and reviewers understand the business scenario, technical architecture, operational controls, evidence, and role alignment without searching through every subfolder.

## Recommended Review Path

1. Read `recruiter-quick-start.md` for a five-minute overview.
2. Review `architecture/architecture-overview.md` and `architecture/system-dependency-map.md`.
3. Open `evidence-index.md` to locate proof of implementation.
4. Review `skills-evidence-matrix.md` for skill-to-artifact mapping.
5. Use the appropriate file in `role-alignment/` for role-specific evaluation.
6. Review `project-outcomes.md` for measurable results and completed acceptance criteria.

## Documentation Scope

This hub covers:

- Active Directory and identity operations
- Windows and Linux systems administration
- Backup, recovery, and disaster recovery
- Capacity and performance management
- Change and configuration management
- Monitoring, patching, and automation
- Security, governance, and evidence handling
- Interview presentation and recruiter navigation

## Lab Classification

This is a simulated enterprise environment built for portfolio demonstration. All system names, users, tickets, incidents, dates, metrics, and reports are fictional but internally consistent. No employer, customer, or production data is included.
