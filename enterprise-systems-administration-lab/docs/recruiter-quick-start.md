# Recruiter Quick Start

## Candidate Demonstration

This portfolio demonstrates the ability to support and administer a small enterprise environment using structured documentation, automation, operational controls, troubleshooting records, and measurable validation.

## Five-Minute Review

### 1. Technical Breadth

The lab covers identity, Windows Server, Linux, virtualization, Microsoft 365, networking, backups, disaster recovery, monitoring, patching, change management, configuration management, and automation.

### 2. Operational Realism

The repository includes completed incidents, service requests, changes, problem records, runbooks, reports, recovery exercises, access reviews, capacity forecasts, validation outputs, and acceptance tests.

### 3. Automation

PowerShell, Ansible, and DSC are used for user lifecycle tasks, health reporting, configuration enforcement, drift detection, backup validation, capacity analysis, and post-change verification.

### 4. Security and Governance

The lab uses least privilege, delegated administration, role-based access, change approval, audit evidence, privileged account standards, backup immutability, and data sanitization controls.

### 5. Best Role Fit

- Help Desk / IT Support
- Junior Systems Administrator
- Infrastructure Support
- Cloud Support Associate
- Microsoft 365 Administrator
- Junior Cloud Engineer
