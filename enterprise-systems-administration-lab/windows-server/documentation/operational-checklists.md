# Operational Checklists

## Daily

- [x] Server reachability reviewed
- [x] Critical/error events reviewed
- [x] Required services checked
- [x] Disk thresholds checked
- [x] Backup freshness checked
- [x] Failed tasks and print queues reviewed

## Weekly

- [x] Local administrators reviewed
- [x] Firewall and RDP scope validated
- [x] SMBv1 state validated
- [x] Share permissions reviewed
- [x] Backup capacity reviewed
- [x] Certificate expiration reviewed

## Monthly

- [x] Approved patches installed
- [x] Post-reboot role validation completed
- [x] Restore test completed
- [x] Capacity report reviewed
- [x] Incident trends summarized
- [x] Evidence package updated
