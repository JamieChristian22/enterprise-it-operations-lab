# Runbook: Server Performance Degradation

1. Define the exact symptom, time window, and affected users.
2. Capture CPU, memory, disk latency, queue length, network utilization, and top processes.
3. Review scheduled tasks, backup jobs, antivirus scans, and recent changes.
4. Check for disk free space below 20% and excessive paging.
5. Stop or restart a process only after confirming ownership and impact.
6. Compare current metrics with the monthly baseline.
7. Escalate sustained resource saturation for capacity planning.
