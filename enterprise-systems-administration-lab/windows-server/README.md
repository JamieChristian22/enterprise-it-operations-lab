# Enterprise Windows Server Administration Lab

Production-style Windows Server 2022 portfolio project covering server builds, roles, file/print services, storage, backup, Event Viewer, scheduled tasks, RDP/firewall hardening, certificates, monitoring, patching, PowerShell, incidents, changes, reports, and validation.

## Environment
- Domain: `northstar.local`
- Domain Controller: `NSS-DC01`
- File Server: `NSS-FILE01`
- Print Server: `NSS-PRINT01`
- Application Server: `NSS-APP01`
- Management network: `10.20.30.0/24`

## Demonstrated Skills
Build and secure Windows Server, install roles, create SMB shares and NTFS permissions, manage storage and backups, troubleshoot services and events, automate with PowerShell, and document operational evidence.
