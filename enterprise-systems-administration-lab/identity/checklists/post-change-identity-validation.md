# Post-Change Identity Validation Checklist

- [ ] Entra Connect scheduler enabled on only one active server
- [ ] Standby server confirmed in staging mode
- [ ] Latest synchronization cycle successful
- [ ] No unresolved connector export errors
- [ ] Password hash synchronization healthy
- [ ] Pilot user can authenticate
- [ ] Group membership synchronized correctly
- [ ] Disabled test account blocked from sign-in
- [ ] No unexpected object deletions
- [ ] Privileged group membership unchanged unless approved
- [ ] Monitoring and alerting operational
- [ ] Evidence attached to the change record
- [ ] Stakeholders notified of completion
