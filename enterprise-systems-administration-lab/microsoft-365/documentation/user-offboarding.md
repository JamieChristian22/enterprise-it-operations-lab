# User Offboarding Procedure

## Immediate Actions

1. Confirm termination authorization and timing.
2. Block user sign-in.
3. Revoke refresh tokens and active sessions.
4. Reset the password to a random administrative value.
5. Remove registered authentication methods when approved.
6. Remove privileged roles.
7. Remove group memberships not needed for retention.

## Data Preservation

1. Convert the mailbox to shared when required.
2. Grant the manager mailbox access.
3. Configure forwarding only with documented approval.
4. Preserve or transfer OneDrive files.
5. Transfer ownership of Teams, Microsoft 365 Groups, SharePoint content, and forms.
6. Record retention requirements.

## Completion

1. Remove licenses after data-preservation actions are confirmed.
2. Hide the mailbox from address lists where appropriate.
3. Remove mobile device access.
4. Record every change.
5. Schedule account deletion according to retention policy.
