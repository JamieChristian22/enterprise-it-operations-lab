# Runbook: SharePoint Permission Issue

1. Confirm site URL, requested access level, and site owner approval.
2. Check group-based access before direct permissions.
3. Check inheritance and unique permissions.
4. Review sharing links and guest status.
5. Add the user to the correct owner, member, or visitor group.
6. Remove unnecessary direct permissions.
7. Validate access in a private browser session.
8. Record the final group and access level.
