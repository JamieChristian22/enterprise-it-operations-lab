# Runbook: Shared Mailbox Access

1. Verify the access request and mailbox owner approval.
2. Confirm whether Full Access, Send As, or Send on Behalf is required.
3. Apply only approved permission types.
4. Allow replication time.
5. Validate permissions in Exchange Online PowerShell.
6. Have the user restart Outlook when necessary.
7. Confirm sending and mailbox access.
8. Record the permission and approval source.
