# Runbook: Mail Delivery Failure

1. Record sender, recipient, timestamp, subject, and nondelivery report.
2. Confirm the recipient and mailbox exist.
3. Run message trace.
4. Review quarantine.
5. Review mailbox forwarding and inbox rules.
6. Review transport rules and connectors.
7. Check accepted domains and DNS when external delivery is affected.
8. Validate mailbox quota.
9. Test delivery.
10. Document the final message state and resolution.
