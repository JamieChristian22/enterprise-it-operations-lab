# Runbook: OneDrive File Recovery

1. Verify the user and identify the missing item.
2. Review the OneDrive recycle bin.
3. Review the second-stage recycle bin.
4. Review version history.
5. Restore the required item.
6. Confirm the correct version and location.
7. For departed users, grant temporary authorized access.
8. Transfer required files.
9. Remove temporary administrative access.
10. Document the restore.
