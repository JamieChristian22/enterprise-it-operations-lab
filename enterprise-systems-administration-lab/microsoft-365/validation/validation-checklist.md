# Microsoft 365 Validation Checklist

## Identity
- [x] User exists
- [x] Display name and UPN are correct
- [x] Usage location is configured
- [x] Account state is correct
- [x] Manager and department are recorded

## Licensing
- [x] Required license is assigned
- [x] Service plans are enabled
- [x] License capacity is available

## Exchange Online
- [x] Mailbox is provisioned
- [x] Primary email address is correct
- [x] Shared mailbox permissions are correct
- [x] Test message is delivered

## Teams and SharePoint
- [x] Team membership is correct
- [x] Team owner count meets standard
- [x] SharePoint access is group-based
- [x] Files are accessible

## Security
- [x] MFA registration is required
- [x] Conditional Access applies as expected
- [x] No privileged role is assigned without approval
- [x] No unauthorized forwarding is configured

## Documentation
- [x] Request and approval are recorded
- [x] Commands or portal actions are documented
- [x] Validation evidence is attached
- [x] Requester is notified
