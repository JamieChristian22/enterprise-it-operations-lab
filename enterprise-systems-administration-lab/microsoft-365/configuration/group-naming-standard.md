# Group Naming Standard

| Group Type | Prefix | Example |
|---|---|---|
| Security group | `SG-` | `SG-Finance-Users` |
| Microsoft 365 group | `M365-` | `M365-Project-Apollo` |
| Distribution group | `DL-` | `DL-All-Managers` |
| Dynamic group | `DYN-` | `DYN-All-Employees` |
| License group | `LIC-` | `LIC-M365-Business-Premium` |
| Conditional Access exclusion | `CA-EXCL-` | `CA-EXCL-Emergency-Accounts` |

Descriptions must include purpose, owner, approval source, and review date.
