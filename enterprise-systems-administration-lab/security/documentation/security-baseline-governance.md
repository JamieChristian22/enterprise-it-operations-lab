# Security Baseline Governance

## Principles

- Pilot before broad deployment.
- Use least privilege.
- Document exceptions.
- Define rollback before enforcement.
- Validate business-critical applications.
- Monitor control drift.
- Review privileged access quarterly.
- Preserve security logs.
- Separate administrative and daily-use accounts.

## Exception Requirements

Every exception must identify:

- Asset
- Control
- Business justification
- Risk owner
- Compensating control
- Approval
- Expiration date
