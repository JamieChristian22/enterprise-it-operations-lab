# Enterprise IT Operations Reporting Suite

A production-style reporting portfolio project for enterprise systems administration. This suite demonstrates how infrastructure data is transformed into executive summaries, operational reports, compliance reports, capacity forecasts, service-level metrics, incident trends, and automated CSV/HTML/Markdown outputs.

## Business Scenario

Northstar Services operates a mixed environment including Windows Server, Linux, Active Directory, Microsoft 365, PKI, patching, backup, monitoring, and service desk operations. Leadership and technical teams require consistent reports to understand:

- Service availability
- Infrastructure health
- Patch compliance
- Security posture
- Certificate risk
- Backup success
- Capacity trends
- Incident performance
- Change success
- Microsoft 365 service status
- SLA performance

## Audiences

| Audience | Reporting Need |
|---|---|
| Executives | KPIs, risk, trends, business impact |
| IT Operations | System health, failures, capacity, remediation |
| Security | Vulnerabilities, privileged access, certificate risk |
| Service Owners | Availability, incidents, change outcomes |
| Auditors | Compliance, evidence, exceptions, control performance |
| Help Desk | Ticket trends, recurring issues, SLA breaches |

## Included Report Categories

- Executive monthly operations report
- Weekly infrastructure health report
- Windows and Linux patch compliance
- Microsoft 365 administration health
- Active Directory health
- Backup and recovery status
- PKI and certificate expiration
- Capacity planning
- Availability and SLA
- Incident metrics and MTTR
- Change success rate
- Security events and vulnerability remediation
- Automated CSV, HTML, and Markdown report generation
