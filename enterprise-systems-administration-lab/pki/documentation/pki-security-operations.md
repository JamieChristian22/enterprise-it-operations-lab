# PKI Security Operations

## Daily

- Confirm Issuing CA service health.
- Confirm CRL and OCSP availability.
- Review failed certificate requests.
- Review CA security events.
- Review certificates expiring within 30 days.

## Weekly

- Review template changes.
- Review privileged group membership.
- Review failed enrollment activity.
- Confirm backups completed.
- Confirm HTTP publication paths are reachable.

## Monthly

- Test one certificate enrollment and revocation.
- Review expiring CA and service certificates.
- Review certificate inventory.
- Review exceptions and weak cryptography.
- Test backup integrity.
