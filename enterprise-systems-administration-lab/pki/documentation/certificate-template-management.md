# Certificate Template Management

## Included Templates

- Northstar Web Server
- Northstar Computer Authentication
- Northstar User Authentication
- Northstar NPS Server
- Northstar OCSP Response Signing
- Northstar Code Signing

## Template Controls

- Appropriate EKUs only
- Minimum approved key size
- Subject name supplied from AD where possible
- Private key export disabled unless required
- Auto-enrollment limited to approved groups
- Manager approval required for high-risk templates
- Renewal period configured before expiration
- Superseded templates documented
