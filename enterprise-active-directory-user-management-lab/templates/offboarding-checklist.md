# Offboarding Checklist

- [ ] HR authorization confirmed
- [ ] Effective time confirmed
- [ ] Account state exported
- [ ] Account disabled
- [ ] Password reset to random value
- [ ] Group memberships removed
- [ ] Active sessions/tokens revoked where applicable
- [ ] Data ownership transferred
- [ ] Account moved to Disabled Users OU
- [ ] Description updated with ticket/date
- [ ] Retention or legal hold recorded
- [ ] Manager notified of completion
