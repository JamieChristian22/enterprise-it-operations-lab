# Object Naming Standard

| Object | Standard | Example |
|---|---|---|
| Global department group | `GG_<Department>_Users` | `GG_Finance_Users` |
| Domain Local resource group | `DL_<Resource>_<Permission>` | `DL_Finance_Share_Modify` |
| Group Policy | `GPO-<Purpose>` | `GPO-Workstation-Security-Baseline` |
| Workstation | `CL##` | `CL01` |
| Domain controller | `DC##` | `DC01` |
| File server | `FS##` | `FS01` |
| Change request | `RFC-AD-###` | `RFC-AD-003` |
| Incident | `INC-####` | `INC-1003` |
| Service request | `SR-####` | `SR-1006` |
