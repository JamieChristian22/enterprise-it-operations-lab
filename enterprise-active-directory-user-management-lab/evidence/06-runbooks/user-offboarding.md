# User Offboarding Runbook

1. Verify HR/manager approval and effective time.
2. Export current group memberships.
3. Disable the account.
4. Reset the password to a random value.
5. Remove non-retention memberships.
6. Add retention tracking group.
7. Move account to Disabled Users OU.
8. Update description with ticket and retention date.
9. Preserve approved data and transfer ownership.
10. Validate account cannot authenticate.
